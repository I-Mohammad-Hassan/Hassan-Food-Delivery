## 📌 About the Project

The **Hassan Food Delivery Dashboard** is a data visualization project developed in Microsoft Power BI to transform food delivery data into meaningful business insights.

The dashboard provides an overview of key performance indicators, food preferences, monthly order trends, payment methods, delivery status, and membership-based transaction analysis.

Interactive filters allow users to explore the data dynamically and analyze different business segments.

## 🎯 Project Objectives

- Monitor total food order quantities and transactions.
- Identify the most popular food items.
- Analyze monthly order quantity trends.
- Compare food categories by customer membership type.
- Understand customer payment preferences.
- Monitor delivered and cancelled transactions.
- Enable interactive data exploration using filters and slicers.

## 📊 Dashboard Features

### 1. Key Performance Indicators (KPIs)

The dashboard highlights key business metrics:

- **Total Quantity:** Approximately 15K
- **Total Transactions:** Approximately 3K

These indicators provide a quick overview of the business's performance.

### 2. Food-Wise Quantity Analysis

A horizontal bar chart displays the most popular food items based on quantity.

| Food Item | Quantity |
|---|---:|
| Samosa | 2,427 |
| Butter Chicken | 2,044 |
| Chole Bhature | 1,310 |
| Masala Dosa | 1,121 |
| Gulab Jamun | 710 |
| Tandoori Chicken | 667 |
| Pav Bhaji | 665 |
| Dal Tadka | 652 |
| Biryani | 616 |
| Ras Malai | 546 |

**Key Insight:** Samosa has the highest quantity among the food items displayed, followed by Butter Chicken.

### 3. Monthly Quantity Analysis

The dashboard uses column and line charts to visualize monthly quantity trends.

| Month | Quantity |
|---|---:|
| January | 3,404 |
| February | 4,376 |
| March | 4,264 |
| April | 3,059 |

**Key Insight:** February records the highest monthly quantity among the four months shown, while April records the lowest.

### 4. Food Category and Membership Analysis

A matrix visual compares food quantities across Gold and Regular membership types.

Food categories include:

- Appetizer
- Beverage
- Breakfast
- Dessert
- Main Course
- Snack

This analysis helps compare category-level activity across membership segments.

### 5. Payment Method Analysis

A bar chart compares quantities by payment method.

- **UPI:** Approximately 9K
- **COD:** Approximately 4K
- **Card:** Approximately 2K

**Key Insight:** UPI is the leading payment method by quantity in the displayed dashboard.

### 6. Delivery Status Analysis

A doughnut chart visualizes transaction status, including:

- Delivered
- Cancelled

This visual helps users understand delivery outcomes and evaluate operational performance.

### 7. Interactive Filter Panel

The dashboard includes interactive slicers for:

- Month
- Payment Method
- Member Type
- Restaurant Type

These filters allow users to explore different data segments and dynamically update the dashboard visuals.

## 📈 Key Business Insights

Based on the displayed dashboard:

1. Samosa is the most popular food item among the items shown.
2. February has the highest monthly quantity, at 4,376.
3. UPI is the most-used payment method by quantity in the displayed data.
4. Main Course has the highest total quantity among the listed food categories.
5. The membership matrix supports comparisons between Gold and Regular customers.
6. Monthly trends help identify changes in food demand.
7. Delivery status analysis provides a visual overview of completed and cancelled transactions.

1. View the screenshot and animated GIF previews above.

3. Download the Power BI report file (`.pbix`) if it is included in the repository.
4. Open the `.pbix` file using Microsoft Power BI Desktop.

6. Explore the charts and matrix to analyze the available metrics.
